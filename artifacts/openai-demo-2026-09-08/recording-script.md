# Apiosk — ChatGPT Developer Mode demonstration

Recording target: the live Apiosk Connect connection in ChatGPT, English UI.
Show the real request, quoted ceiling, human approval, provider result and saved-result follow-up. Do not substitute a fixture for live footage.

## Sequence

1. Developer Mode enabled: Settings → Security and login. Show only the Developer Mode area.
2. Apiosk Connect: show the installed connection and its MCP tools. Keep credentials and unrelated conversations out of frame.
3. New chat, with Apiosk Connect selected. Type:
   > Find the official KVK company profile of Mollie B.V. Show me the plan and total price before buying any data.
4. Hold on the plan and total price. Explain the company-name lookup and subsequent profile retrieval when both appear in the actual plan.
5. The account owner clicks Approve in the card. Record the resulting progress and any identity selection. Choose a company only from the returned evidence.
6. Show the final record, source and actual charge. Use only values actually returned by KVK.
7. Follow up:
   > Show the saved result again, without purchasing any new data.
8. Finish on the saved result and its source.

## English narration

“This is Apiosk running inside ChatGPT in Developer Mode. The MCP connection gives ChatGPT access to Apiosk’s data workflows.

I start with a question: find the official KVK company profile of Mollie B.V.

Apiosk prepares a plan and shows the total price before any provider data is purchased. If the company name is ambiguous, I select the right company from the returned records.

After I approve the displayed plan, Apiosk retrieves the data. The result stays in the conversation, with its source and the actual amount charged.

I can return to that saved result without buying the same data again.”
